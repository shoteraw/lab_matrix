# Matrix — лабораторная работа

Проект реализует класс `Matrix` для целочисленных матриц произвольного размера.
Матрица хранится как динамический массив строк; поля скрыты, а доступ к элементам
выполняется только через методы класса.

Возможности класса:

- пустая, единичная и нулевая матрицы через разные конструкторы;
- ввод с клавиатуры, случайное заполнение числами от 0 до 99 и печать;
- получение и изменение элемента с проверкой индексов;
- вычисление суммы элементов и транспонирование;
- исключения для отрицательных размеров и неверных индексов.

## Сборка и запуск

```powershell
g++ -std=c++17 -Wall -Wextra main.cpp Matrix.cpp -o matrix_lab
.\matrix_lab.exe
```

Программа показывает работу всех конструкторов, заполняет `M2` по формуле
`i * j`, случайно заполняет `M3`, запрашивает шесть чисел для `M4`, выводит сумму
`M3`, транспонированную `M4` и обработку исключений.

Пустая матрица не выделяет память. Память для непустой матрицы выделяется
построчно и освобождается в обратном порядке в деструкторе.
